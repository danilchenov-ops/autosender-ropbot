# Память проекта «Виртуальный РОП»

**Читать первым делом в любой новой сессии Claude.** Эти файлы доступны из любого чата
через MCP-сервер `ropbot` (`ssh_run`, `sql`, `write_file`) — они не привязаны к конкретной
переписке и не теряются при её закрытии.

Быстрый старт:

    cat /opt/ropbot/memory/*.md

## Файлы

| Файл | О чём |
|---|---|
| `infrastructure.md` | Сервер, доступы, что собирается, схема базы, этапы, смета |
| `analytics-rules.md` | **Обязательные** правила счёта. Нарушение = ложные обвинения менеджеров |
| `lead-scoring.md` | Скоринг заявок по поведению, маркировка в CRM, замер точности |
| `robot-obzvon.md` | Прикидка по автообзвону роботом (варианты, деньги, сценарий) |

## Порядок работы

1. Прочитать `analytics-rules.md` перед любым отчётом или выборкой.
2. Проверять выводы **запросом к базе**, а не памятью: настоящее состояние проекта —
   в Postgres на этом сервере, документы лишь описывают контекст и решения.
3. Что-то важное решили или выяснили — дописать в соответствующий файл здесь
   (`write_file` по пути `memory/<файл>.md`) и продублировать в проект Claude
   «Виртуальный РОП», если сессия к нему подключена.

Копия этих же документов лежит в проекте Claude «Виртуальный РОП» (docs `claude/*.md`).
При расхождении **более свежей считается версия на сервере** — её видят все сессии,
включая те, что работают без привязки к проекту.
